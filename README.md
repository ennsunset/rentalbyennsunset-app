# RentByEnn

A frontend-only premium car rental experience built with Next.js, React, TypeScript, Tailwind CSS, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Included

- Responsive landing page and mobile navigation
- Search by location and pickup/return dates
- Filterable fleet with vehicle search, favorites, and sample inventory
- Vehicle detail and reservation modal
- Sample Unsplash photography
- Demo interactions; checkout, authentication, inventory APIs, MongoDB, and Stripe are not connected

Images are loaded from Unsplash URLs and require an internet connection.
